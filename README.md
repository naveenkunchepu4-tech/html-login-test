# HTML Login Test Project

This project is a simple HTML login page that includes a form for user authentication. It is designed to demonstrate basic web development skills, including HTML structure, CSS styling, and JavaScript functionality.

## Project Structure

```
html-login-test
├── src
│   ├── index.html       # HTML structure for the login page
│   ├── styles
│   │   └── style.css    # CSS styles for the login page
│   └── scripts
│       └── script.js    # JavaScript for handling form submission
└── README.md            # Documentation for the project
```

## Features

- User-friendly login form with fields for username and password.
- Responsive design with CSS for a clean and modern appearance.
- JavaScript functionality to handle form submission and display a success message.

## Usage

1. Clone the repository to your local machine.
2. Open the `src/index.html` file in a web browser to view the login page.
3. Enter a username and password, then submit the form to see the success message.
